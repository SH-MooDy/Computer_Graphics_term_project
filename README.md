# 실시간 물리 기반 당구 게임 만들기

### 조건
 - 윈도우를 당구대와 같은 비율로 생성한다.
 - 윈도우의 4면이 당구대의 벽면에 해당한다.
 - 공을 움직일 때 바닥의 마찰력과 공들간의 충돌 및 반사 기능을 구현한다.
 - top view 와 카메라 뷰를 만들고 원하는 형식으로 보여주기.
 - 공과 큐대를 만들고 게임을 진행하는데 필요한 힘과 방향 그리고 큐대가 공의 어느 위
치를 충돌하는지에 따른 움직임을 만들어 보아라.
